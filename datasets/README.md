# `datasets/`

Synthetic sample data used to demo and test the reconciliation pipeline.
Nothing here is real financial data — all files will be generated/fabricated
for the hackathon demo (minimum 50 transaction records per the problem
statement).

| Folder | Represents |
|---|---|
| `bank_statements/` | Bank-side transaction records |
| `payment_gateway/` | Razorpay/gateway-side transaction records |
| `settlement_reports/` | Merchant settlement records |
| `invoices/` | Invoice/accounting records |

CSV files will be added here once sample data generation begins.
