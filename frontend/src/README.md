# Frontend — `src/`

Next.js (App Router) + TypeScript source root.

| Folder | Purpose |
|---|---|
| `app/` | Route segments and pages (App Router convention) |
| `components/` | Reusable UI components (upload widget, match table, exception cards, dashboard charts) |
| `hooks/` | Custom React hooks (e.g. `useUpload`, `useReconciliationData`) |
| `lib/` | API client, fetch wrappers, formatting helpers |
| `types/` | Shared TypeScript types/interfaces mirroring the backend schemas |
| `styles/` | Global styles / Tailwind config extensions |

No pages or components have been implemented yet — this is structure only.
